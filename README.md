# Express.js Project

## 📌 Deskripsi

Aplikasi backend menggunakan Express.js.

---

## 📞 Instalasi

Ikuti langkah-langkah berikut untuk menginstal dan menjalankan proyek ini:

### 1️⃣ Instalasi Express Generator

```sh
npm install -g express-generator
```

### 2️⃣ Instalasi Nodemon

```sh
npm install -g nodemon
```

### 3️⃣ Install Dependencies

```sh
npm install dotenv --save
npm install mongoose --save
npm i http-status-codes
npm i multer
npm install nodemailer mustache
```

---

## ⚡ Teknologi yang Digunakan

- **Node.js & Express.js** - Backend framework.
- **MongoDB & Mongoose** - Database NoSQL.
- **Nodemailer & Mustache** - Pengiriman email.
- **Multer** - Upload file.
- **dotenv** - Manajemen konfigurasi.
- **http-status-codes** - Penanganan status error.

---

## 🛠 Perintah NPM

| Perintah      | Deskripsi                      |
| ------------- | ------------------------------ |
| `npm install` | Install dependencies           |
| `npm start`   | Jalankan server production     |
| `npm run dev` | Jalankan server dengan nodemon |
